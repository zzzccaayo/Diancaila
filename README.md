# 点菜啦 · 微信点菜小程序

一个基于微信云开发的简单点菜小程序：

- **点菜页**：左侧分类、右侧菜品，加减数量，底部购物车栏
- **确认订单页**：填写桌号、备注，调整数量，提交订单
- **我的订单页**：查看历史订单，下拉刷新
- **主人模式**：绑定为主人后可查看所有订单、标记完成，并在手机上编辑菜单（图片、菜名、分类、增删菜品）
- 每道菜的价格都是「一个亲亲」😘

订单保存在云数据库 `orders` 集合中；若云开发未开通，会自动保存到本机缓存，方便先跑起来。

## 使用方法

把本仓库的 `miniprogram/` 目录内容覆盖到微信开发者工具中新建的云开发项目的 `miniprogram/` 目录，然后在云开发控制台创建 `orders` 集合即可。

## 修改菜单

菜单保存在云数据库 `dishes` 集合（首次打开自动写入默认菜单）。主人在点菜页点 ✏️ 编辑菜品、点右下角 ＋ 添加新菜。
默认菜单定义在 `cloudfunctions/kitchen/index.js` 的 `DEFAULT_DISHES`。

需要上传部署 `cloudfunctions/kitchen` 云函数。
