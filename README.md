# 点菜啦 · 微信点菜小程序

一个基于微信云开发的简单点菜小程序：

- **点菜页**：左侧分类、右侧菜品，加减数量，底部购物车栏
- **确认订单页**：填写桌号、备注，调整数量，提交订单
- **我的订单页**：查看历史订单，下拉刷新

订单保存在云数据库 `orders` 集合中；若云开发未开通，会自动保存到本机缓存，方便先跑起来。

## 使用方法

把本仓库的 `miniprogram/` 目录内容覆盖到微信开发者工具中新建的云开发项目的 `miniprogram/` 目录，然后在云开发控制台创建 `orders` 集合即可。

## 修改菜单

编辑 `miniprogram/data/menu.js`。
